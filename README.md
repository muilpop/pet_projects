## Основные инструменты

- **Язык программирования:** Python 3
- **Обработка и анализ данных:** Pandas, NumPy
- **Статистический анализ:** SciPy, Statsmodels
- **Визуализация данных:** Matplotlib, Seaborn
- **Среда разработки:** Jupyter Notebook
- **Работа с версиями проектов:** Git, GitHub

## Цель репозитория

Практическое применение знаний в области аналитики данных и продуктовой аналитики: исследование данных, проверка гипотез, проведение A/B-тестов, анализ пользовательского поведения и подготовка рекомендаций на основе данных.
