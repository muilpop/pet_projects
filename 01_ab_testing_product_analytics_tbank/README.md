# A/B-тестирование формы оплаты

## О проекте

Проект посвящён анализу результатов A/B-тестирования новой формы оплаты с автозаполнением реквизитов.

Цель эксперимента — оценить, влияет ли изменение формы оплаты на конверсию пользователей в успешную оплату.

## Данные

В анализе используются два набора данных:

- `df_users` — информация о пользователях и их принадлежности к экспериментальным группам.
- `df_payments` — информация о попытках оплаты и прохождении этапов платёжной формы.

## Методология

В ходе проекта выполнены следующие этапы:

1. Первичный анализ данных: структура, типы переменных, пропуски и дубликаты.
2. Проверка корректности разделения пользователей на экспериментальные группы.
3. Сравнение групп по характеристикам пользователей: возрасту, городу и типу устройства.
4. Анализ пользовательской воронки оплаты.
5. Расчёт основной метрики — конверсии пользователей в успешную оплату.
6. Статистическая проверка гипотез с помощью двустороннего Z-теста для двух независимых пропорций.
7. Расчёт абсолютного и относительного прироста, а также 95%-го доверительного интервала.

## Основные результаты

| Метрика | Группа A | Группа B |
|---|---:|---:|
| Количество пользователей | 752 | 752 |
| Успешные пользователи | 493 | 604 |
| Конверсия | 65,56% | 80,32% |

**Результат эксперимента:**

- Абсолютный прирост конверсии: +14,76 п.п.
- Относительный прирост конверсии: +22,52%.
- Z-statistic: −6,44.
- p-value: 1,18 × 10⁻¹⁰.
- 95%-й доверительный интервал разницы конверсий B − A: [10,33; 19,19] п.п.

## Вывод

Новая форма автозаполнения ревизитов имеет статистически значимый эффект, доля успешных оплат выросла на 22,52%. Абсолютный прирост целевой метрики составил 14,76 п.п.

Таким образом, рекомендуется запускать новую конфигурцию формы с автозаполнением реквизитов уже для всех пользователей.
